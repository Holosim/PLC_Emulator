# Theme park attraction documentation standards

Optional, domain-specific reference — not part of the default project
template. Pull this into a project's `docs/` folder only when the
project actually is a theme park attraction or ride system; for
everything else, this file doesn't apply and shouldn't be present.

## Standards cascade

When a specification isn't available at a given level, fall back to
the next level down:

1. Disney GE&T Documentation Standards
2. TWDC Documentation Standards
3. ASTM F2291 (Theme Park Attractions)
4. INCOSE Requirements Documentation Standards (e.g. System Description
   Document / SDD)
5. IEC 61508
6. ISO-13849 (Functional Safety)
7. ANSI E1.47 (Rigging Systems)
8. ASME Mechanical (e.g. Y14.5)
9. UL 508A or NFPA 79 (electrical control panels)
